# CUSTOM-STRING-CLASS-IMPLEMENTATION-IN-MODERN-C-

A menu-driven C++ application that implements a **Custom String Class** without using the built-in `std::string` library. This project demonstrates Object-Oriented Programming concepts such as constructors, destructors, dynamic memory allocation, friend functions, and operator overloading while recreating commonly used string operations from scratch.

 Description :

This project was developed to understand the internal working of string manipulation by implementing a custom string class in C++. Instead of relying on the Standard Template Library (STL), the project manually manages memory and performs string operations using character arrays and pointers.

The application includes overloaded operators and user-defined implementations of standard C string functions, providing hands-on experience with Object-Oriented Programming, memory management, and operator overloading.

 Features :

1 . Operator Overloading :

- Assignment (`=`)
- Concatenation (`+`)
- Subscript (`[]`)
- Greater Than (`>`)
- Less Than (`<`)
- Greater Than or Equal (`>=`)
- Less Than or Equal (`<=`)
- Equality (`==`)
- Inequality (`!=`)
- Input (`>>`)
- Output (`<<`)

2 . Custom String Operations :

- String Length
- String Reverse
- Substring Search
- Uppercase Conversion
- Lowercase Conversion
- Character Search (`strchr`)
- Reverse Character Search (`strrchr`)
- String Copy (`strcpy`)
- String Compare (`strcmp`)
- String Concatenation (`strcat`)
- Partial String Copy (`strncpy`)
- Partial String Compare (`strncmp`)
- Partial String Concatenation (`strncat`)
